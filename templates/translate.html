命令行翻译

对于完整的 ASS 字幕翻译（含术语提取、两遍翻译、审校），使用命令行：

# 测试 API
python subtitle_translator.py test-api

# 下载视频
python subtitle_translator.py download "https://youtube.com/watch?v=xxx"

# 翻译 ASS 字幕
python subtitle_translator.py optimize "path/to/subtitle.ass"

# 跳过审校（加快速度）
python subtitle_translator.py optimize "subtitle.ass" --no-review
